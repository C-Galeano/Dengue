Methodology: CRISP-DM

The project follows CRISP-DM (Cross-Industry Standard Process for Data Mining), the most widely used process for data science projects. It has six phases. Each one has its own page explaining what the phase is and how this project implements it, plus a notebook in notebooks/.

An iterative cycle

CRISP-DM is not a straight line. In this project:

  • Iteration 1: weekly dengue forecasting → binary dengue screening with Colombian data (Tuluá).
  • Phase 5 → Phase 1: the evaluation judged the binary model too narrow. The objective was widened to a "smart hospital" differential diagnosis among arboviruses, with explanations for the clinician.
  • Phase 1 → Phase 2: no Colombian source has symptoms for Zika or chikungunya, so the data search moved to Brazil's SINAN, and the Tuluá data became an external validation set.
