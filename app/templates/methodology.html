Methodology: CRISP-ML(Q)

The project follows CRISP-ML(Q) (CRoss-Industry Standard Process for the development of Machine Learning applications with Quality assurance methodology; Studer et al., 2021). It adapts CRISP-DM to machine learning: business and data understanding form one phase, every phase identifies its risks and how to check them (the "Q"), and a final phase monitors and maintains the model after deployment. Each phase has its own page explaining what the phase is and how this project implements it, plus a notebook in notebooks/.

An iterative cycle

CRISP-ML(Q) is not a straight line. In this project:

  • Iteration 1: weekly dengue forecasting → binary dengue screening with Colombian data (Tuluá).
  • Phase 4 → Phase 1: quality assurance judged the binary model too narrow (ROC-AUC ≈ 0.63). The objective was widened to a "smart hospital" differential diagnosis among arboviruses, with explanations for the clinician.
  • Within Phase 1: no Colombian source has symptoms for Zika or chikungunya, so the data search moved to Brazil's SINAN, and the Tuluá data became an external validation set.
  • Phase 6 → Phase 1: monitoring with 2025 data shows drift in where cases come from, so the next iteration retrains with recent and local data.
