Second iteration of this phase
With clinical features only, the macro ROC-AUC was about 0.71, below the 0.80 target. Exploration (Phase 1) had shown that chikungunya concentrates in a few states and that circulation changes by month. Adding where and when the patient consults — the local pre-test probability a clinician already uses — raised it above 0.80. Caveat: part of the state effect may reflect each state's laboratory practices.

SINAN codes yes/no as 1 = Yes, 2 = No; they become 1/0. Ages outside 0–110 and onset intervals outside 0–30 days become missing. All features are numeric, so tree models need no encoding.

3. Balanced samples

Laboratory-confirmed dengue is ten times more frequent than the other classes. A random sample of equal size per class keeps the model from learning only "dengue is the most common", and makes the probabilities comparable across diagnoses.
