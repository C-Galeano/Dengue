1 Project title

Arbovirus Differential Diagnosis with Explainable Artificial Intelligence: a clinical decision-support tool to distinguish dengue, chikungunya and other febrile illnesses at the first consultation.

2 Problem statement and justification

Problem. Dengue and chikungunya are transmitted by the same mosquitoes and share most of their symptoms (fever, headache, muscle and joint pain, rash). At the first consultation there are no laboratory results yet, so the clinician has to decide with symptoms and context alone. Confirmation (NS1, RT-PCR, serology) takes time, and missing a dengue case is the most dangerous error because of the risk of severe disease.

Justification. A model that estimates the probability of each diagnosis, and shows which findings drove it, can support early triage while the laboratory result arrives. We trained it on {{ "{:,}".format(info.data.n_total) }} laboratory-confirmed cases from SINAN (Brazil, {{ info.data.year }}), using {{ info.features|length }} inputs available at the bedside. Explainability (SHAP) keeps the suggestion transparent, and the decision threshold (P(dengue) ≥ {{ threshold_pct }}%) was set to catch at least {{ (info.target_dengue_recall * 100)|int }}% of dengue cases.

3 Project objectives

General objective

Develop and validate an explainable machine learning model that supports the differential diagnosis of dengue, chikungunya and other febrile illnesses in a febrile patient at the first consultation.

Specific objectives

  1. Prepare a clean dataset from the SINAN surveillance files (Brazil), defining three classes: dengue, chikungunya and other febrile illness.
  2. Compare a linear baseline (Logistic Regression) with tree-based models using 5-fold stratified cross-validation, and select the best by macro ROC-AUC (selected: {{ info.model_name }}).
  3. Set a decision threshold that reaches the target dengue recall ({{ (info.target_dengue_recall * 100)|int }}%).
  4. Explain every prediction with SHAP values so clinicians can see which findings weighed most.
  5. Validate the model over time and externally on Colombian data (SIVIGILA Tuluá), and report its limitations.
  6. Deliver a web application to register consultations, update each patient's clinical history and re-run the diagnosis.
4 Reference framework (optional)
  • Clinical: dengue and chikungunya are arboviruses with overlapping symptoms; diagnosis is confirmed in the laboratory.
  • Epidemiological: local circulation (state and month) changes the pre-test probability of each disease.
  • Technical: gradient-boosted trees (XGBoost, LightGBM), Logistic Regression, SHAP for explainability and scikit-learn for the pipeline.
  • Data: SINAN (DATASUS, Brazil) for training; SIVIGILA Tuluá (Colombia) for external validation.
5 Methodology and development timeline

The project follows CRISP-ML(Q), the machine-learning version of CRISP-DM. Quality assurance uses a reserved 20% test set ({{ "{:,}".format(info.data.n_test) }} cases) that is never used for training. See each phase in detail.
